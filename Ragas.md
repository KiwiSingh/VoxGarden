# Raga-inspired sounds and Western note sets

Choose **Root / Sa** to match your song's tonic. Select a raga directly, or choose a starting sound under **Raga-inspired choirs**. The eight sounds use restrained unison, octave and optional fifth layers; Malkauns does not add a missing Pa. The raga overrides the Western Scale selector until set to Off. Ordinary sound presets retain the current musical note set.

The Western name describes the equal-tempered pitch collection. It does not identify the key of an arbitrary input recording. Related-major labels describe the same note collection, or a subset, while **Sa remains the tonic you selected**. For example, C Yaman uses the C Lydian collection, also found in G major; it does not turn Sa into G.

| Raga | Notes with Sa = C | Western collection | Related major collection |
|---|---|---|---|
| [Yaman](https://darbar.org/raga/yaman/) | C D E F# G A B | C Lydian | G major, same notes |
| [Bhupali](https://darbar.org/raga/bhoopaali/) | C D E G A | C major pentatonic | C major subset |
| [Kafi](https://tanarang.com/raag-kafi/) | C D Eb F G A Bb | C Dorian | Bb major, same notes |
| [Bhairavi (Hindustani)](https://darbar.org/raga/bhairavi/) | C Db Eb F G Ab Bb | C Phrygian | Ab major, same notes |
| [Bhairav](https://darbar.org/raga/bhairav/) | C Db E F G Ab B | C double harmonic major | No ordinary major/minor equivalent |
| [Malkauns](https://tanarang.com/raag-malkauns/) | C Eb F Ab Bb | C minor pentatonic with b6 replacing 5 | Ab major subset |
| [Durga](https://tanarang.com/raag-durga/) | C D F G A | C suspended pentatonic (1 2 4 5 6) | C major subset |
| [Hamsadhwani](https://darbar.org/raga/hamsadhwani/) | C D E G B | C major pentatonic with 7 replacing 6 | C major subset |

The Western relationships are calculated from these note sets. Selecting another Sa transposes both the sound and the displayed note names. Notes are spelled by degree, including correct sharps/flats; rare keys can show double accidentals. The root chooser and Live-facing key names use international notation: B means B natural and Bb means B flat, including in the German interface.

These are **raga-inspired choir textures with note constraints**, not an automatic classical raga performer. Pakad, melodic hierarchy, direction-specific movement, meend, gamakas and traditional intonation are not generated by a pitch mask. The source vocal still supplies the phrasing. Some ragas admit variants or additional notes in performance; this release implements the basic sets listed above, not every treatment. See the linked performers/educators' descriptions for those distinctions.

DSP and AI printing use the same selected note mask. MIDI-chord and Chromatic modes retain their explicit control rules; choosing a raga in the interface selects Scale harmony mode. During printing, input monitoring stays dry, and mute/solo behaviour is unchanged.

## Voice-cast variants in 1.0

Each raga submenu contains its original choir plus Female choir / male lead and Male choir / female lead. This adds sixteen sounds. Both new variants retain the selected Sa and raga mask, use six singers, and select the relevant neural reference pool. Their DSP formants and registers also change. In five-note ragas, an octave uses five scale steps rather than seven; Malkauns adds no Pa. Raga grammar and phrasing remain supplied by the source vocal. Larger register shifts may need adjusting to suit your vocal range.
