# VoxGarden 2.1 preview validation

Native arm64 Release build, Apple M3, 16 GB. Version 2.1.0 in the VST3/standalone bundles; both ad-hoc signed and signature-verified. The public GitHub release remains 2.0.0.

- 115 native checks passed against the final signed VST3. Includes the existing score, DSP, host-state, file transfer, raga, preset and UI checks.
- pluginval v1.0.4 passed at strictness 10 against the same final VST3.
- New tests cover disk-backed last-selected appearance across fresh processor instances, per-project restoration without rewriting that preference, corrupt-file fallback, 24-voice state restoration, old-state migration clearing stale extra controls, unchanged original parameter indices and voice-count normalization, all three new presets, inherited voicing/tone when an older raga cast is expanded to 24, third-bank control visibility and cross-bank solo.
- A real offline print produced a mix and all 24 stereo stems with identical 216000-sample lengths. Soloing voice 24 yielded an audible final stem and a silent voice-1 stem. Expanded audio/AI buffers use 48 stem channels and 24 singer channels; legacy fake-AI-input alignment/mixing checks still pass.
- Synthetic 48 kHz benchmark: 8 voices processed 3.2 seconds in 0.309429 seconds (~9.7% of one core); 24 voices took 0.848307 seconds (~26.5%). Latency remains 9216 samples (192 ms). Workload, sample rate and machine affect results. This is not an Ableton session CPU measurement or a listening-quality guarantee.
- Screenshot review verified the third bank, full 24-singer stage, current preset label and non-overlapping control layout. New preset/bank names have all five interface translations.

Only explicit user theme/light-dark changes save Appearance.json in Library/Application Support/VoxGarden. Construction reads the preference; saved projects restore their own appearance without replacing it. No preferences I/O occurs in processBlock. Appearance tests use isolated temporary files and do not rewrite the user's preference.

Original 2.0 sound parameter IDs, indices and ranges are retained. 112 voice controls and Additional Choir Voices are appended, for 188 sound parameters plus wrapper bypass. The original Choir Voices is still 1–8; total is Choir Voices + Additional Choir Voices (0–16). The plugin menu presents one 1–24 choice. Existing Snap collections may need the added controls configured/exposed. A complete new 24-voice SnappySnap morphing session and naturalness audition in Live remain unverified; prior 2.0 user confirmation is not extended to this build.

Abbey Ensemble 24, Chamber Ensemble 16 and Velvet Abbey 24 are original DSP textures, not Cymatics recordings or an Abbey Road sample library. This adds singer parts, not 24 distinct neural models. The existing optional voice-conversion reference pack cycles references for larger choirs; no new 24-singer neural conversion has been timed or listening-verified. Existing score-model downloads can be reused. MIDI import still requires exporting a standard .mid from Live first.

## Amphitheatre and genre update

The original native perspective stage uses tiered geometry and numbered singer figures, high/low camera elevation, display-only collision separation and a guaranteed seating fallback. Tests cover all 24 singers sharing one audio position: every marker remains separately selectable while source pan/depth remain unchanged. Real component mouse events verify click-only selection, individual pan/depth dragging, empty-space drag rejection and stage M/S targeting the selected voice. Camera changes do not write audio positions. Selecting a singer switches to its matching bank and highlights its row. Screenshot review covers the new stage. This is a 2.5D view over the existing pan/delay controls, not HRTF or a new 3D audio renderer.

Twelve new genre sounds bring the menu to 77 entries, with Bollywood, Italodisco, disco polo and classical submenus. Tests verify preserved song root/raga, bounded placement/formants and pentatonic-aware octave voicing. They are original DSP production starting points, not sampled choirs, contextual composition or authentic genre-performance models. Naturalness/genre suitability still require a listening audition in Live. The final signed VST3 passed pluginval strictness 10; host parameter count stays 188 sound controls plus wrapper bypass.
