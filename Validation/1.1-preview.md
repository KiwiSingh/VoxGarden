# VoxGarden 1.1 source preview validation

Test machine: Apple M3, 16 GB; native arm64 Release build. This is a preview of score-driven speech-to-singing, not a trained singing model or a replacement for listening review.

- Native checks passed, including MIDI tempo maps, note lengths/rests, Unicode score text, editable note-name octave round trips, monophonic audio pitch extraction, invalid/overlapping score rejection, prompt cancellation of child process groups and per-instance score/theme state restoration.
- Existing harmony/raga/cast, per-voice mute/solo, channel capture, offline stems and dry-monitor checks passed.
- Tracktion pluginval v1.0.4 passed at strictness 10 on the initial signed 1.1 preview. A subsequent window-only patch makes Notes + lyrics float above the host; native checks and VST3 scan/state checks were rerun for that build. Live clip dragging still needs host verification.
- VST3 host scan, instantiation and state round trip passed. Host parameter count remains 76: 75 sound controls plus wrapper bypass. Score, lyric language/voice and themes are non-sound state; edits notify the host that state changed.
- Factory-menu and language switching checks passed. Native screenshots cover all five interface locales and new theme families in light/dark variants.
- A fresh private Python 3.11.13 setup completed without global package changes. The embedded setup code verified all 18 model assets against the pinned SHA-256 manifest, then profiled actual Core ML execution before marking the runtime ready.
- English, Hindi, German, Japanese, Russian and Dutch neural renders returned correctly sized 2.8-second WAVs and silent rests. Ten voice styles are available; the six-language smoke run used F1.
- Short-phrase speech synthesis measured approximately 0.3–0.9 seconds warm on this machine. A four-word D4/C4/D4/A4 score took 6.85494 seconds including initial model work; repeating it with cached syllables took 0.06375 seconds. Output duration was 3.8 seconds. Median voiced pitch errors in its four notes were +1.03, +0.10, +0.28 and -1.30 cents. Timings vary with compilation/cache state and load.
- Neural sessions request Core ML with CPUAndGPU, ahead of CPU fallback graph operations. This does not prove every Core ML operation physically executes on the GPU. PSOLA timing/pitch and file handling use CPU. The new renderer never invokes Seed-VC.

SnappySnapFX end-to-end morphing is user-confirmed with Electric Smudge's official seven-day trial (2026-10-25); this is a user report, not an additional automated test. Live's internal `.alc` clip transfer and warp/trim reconstruction remain unverified. Standard MIDI and supported audio file paths are accepted. Audio transcription is monophonic and needs correction. Naturalness, consonants on very short notes, extreme transpositions and long held syllables require auditioning.

## Reproduce

After building the targets documented in the README:

```sh
build/VoxGardenCheck_artefacts/Release/VoxGardenCheck \
  build/VoxGarden_artefacts/Release/VST3/VoxGarden.vst3 /tmp/voxgarden-screens
build/VoxGardenCheck_artefacts/Release/VoxGardenCheck --neural-setup
build/VoxGardenCheck_artefacts/Release/VoxGardenCheck --neural-smoke /tmp/voxgarden-neural-smoke
```

The last two commands use the same embedded setup and process-launch code as the plugin UI. `--neural-setup` downloads assets if absent. Ordinary native checks do not download models. The new optional runtime requires Apple Silicon macOS 14+.
