# VoxGarden 3.0.0 — Amphi validation

Native arm64 Release build, Apple M3, 16 GB. DSP target: macOS 12+. Neural score singing: Apple Silicon macOS 14+.

- 115 native checks passed against the final signed 3.0.0 VST3, including DSP, scale/raga voicing, score timing, chord leadership, MIDI overlap handling, dry transfer, theme preferences, 24-voice state and migration, genre sounds, stage interaction and localized UI screenshots.
- pluginval v1.0.4 passed at strictness 10 against the same signed VST3.
- Two offline score-runtime regressions passed: real-PSOLA chord pitches, full overlapping-note length and peak ceiling, plus deterministic velocity/leader mix gains. No model downloads are required for these tests.
- VST3 and standalone have CFBundleShortVersionString 3.0.0 and are arm64, ad-hoc signed and signature-verified. The UI reads VoxGarden 3.0.0 / AMPHI. Plugin identity is retained, with 188 sound parameters plus wrapper bypass; original 2.0 parameter IDs, order and ranges are unchanged.
- A real offline print writes a mix and all 24 aligned stereo stems; cross-bank solo is respected. Legacy AI-input alignment/mixing checks still pass. No new 24-singer neural conversion has been timed or listening-verified.
- Native mouse tests cover all 24 singers sharing one audio position: every marker is separately selectable without moving audio positions. Click selection, individual pan/depth dragging, stage M/S, empty-space drag rejection and camera invariance pass. The selected singer opens the matching bank and highlights its row. The projection is native 2.5D geometry over existing pan/delay controls, not HRTF audio.
- All twelve genre sounds preserve the selected root/raga and use bounded voice settings. Pentatonic-aware octave voicing passes. There are 77 factory sounds. Genre/abbey sounds are original DSP starting points, not sampled choir libraries or complete genre performance models.
- Last-selected appearance saves atomically and restores for fresh instances. Project restoration does not overwrite the global preference. Tests use temporary preference files; no preferences I/O occurs in processBlock.
- Five localized READMEs retain language selectors and actual coffee emoji support links. New release screenshots show Amphi; package source, licences, examples, guarded installer, legacy setup wrapper and validation logs are included. SHA256SUMS.txt verifies the ZIP. Neural weights download inside the plugin rather than being bundled.

The user confirmed the preceding 24-voice amphitheatre/genre feature preview works as intended on 2026-10-26. Earlier Ableton dry-WAV auditioning and SnappySnapFX morphing with Electric Smudge's official seven-day trial are user-confirmed. These are user reports, not independent automated host sessions. A full new 24-voice SnappySnap morphing session remains unverified; added controls may need configuring in existing Snap collections.

Development measurements on this M3 processed 3.2 seconds of audio in 0.309429 seconds for 8 voices (~9.7% of one core) and 0.848307 seconds for 24 (~26.5%). Latency is unchanged at 9216 samples at 48 kHz (192 ms). These synthetic measurements vary with workload and are not a Live-session CPU or listening-quality guarantee.

Known limitations: export Live MIDI clips to .mid before importing; direct internal MIDI-clip dragging remains unsupported. Audio transcription is monophonic. Later host tempo changes do not retime the imported score. Dry transfer is native file-copy drag, not automatic clip insertion. Neural output is speech retimed/pitched to the score; consonants, long notes and extreme transpositions need auditioning. DSP correction analyses one source pitch at a time and does not independently correct every pitch in a polyphonic dry mix.

See [workflow](../Singing.md) and [development neural measurements](1.1-preview.md). Core ML requests CPUAndGPU ahead of CPU graph fallback; PSOLA uses CPU and the score renderer never invokes Seed-VC. Reproduce checks with VoxGardenCheck, pluginval --strictness-level 10 and Singing/test_runtime.py in the private singing Python environment.
