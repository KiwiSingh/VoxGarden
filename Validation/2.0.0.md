# VoxGarden 2.0.0 release validation

Apple M3, native arm64 Release build. DSP deployment target: macOS 12. Neural score singing requires Apple Silicon macOS 14+.

- 91 native checks passed against the signed 2.0.0 VST3, including DSP, scale/raga membership, voice controls, score parsing, MIDI tempo and overlapping-note lengths, chord leadership/inversions/ties, editable velocity, selection/deletion, native dry-file transfer payloads, state round trips, parameter counts and localized screenshots.
- Tracktion pluginval v1.0.4 passed at strictness 10 against the same signed VST3.
- Two offline PSOLA/mixer regressions passed (the gain-ratio test uses a deterministic retiming fixture; the chord test exercises real PSOLA): overlapping chord pitches, output length, clipping ceiling, velocity and leader-gain ratios. They use cached synthetic syllables and do not download models.
- CFBundleShortVersionString is 2.0.0 in VST3 and standalone bundles. Both are arm64 and ad-hoc signed; signature verification passed. Plugin IDs and 75 sound parameters plus wrapper bypass are retained.
- The package includes five localized READMEs with language selectors and Ko-fi sections, screenshots, complete source, licences, examples, the guarded VST3 installer and the optional legacy AI setup wrapper. SHA256SUMS.txt verifies the ZIP. Neural model weights are downloaded inside the plugin rather than included in the ZIP.

The user confirmed the Ableton Live dry-vocal audition workflow works as intended on 2026-10-25. SnappySnapFX end-to-end morphing is user-confirmed using Electric Smudge’s official seven-day trial. These are user reports, not independent automated host tests.

Known host limitation: export Live MIDI clips to .mid before import. Direct internal MIDI-clip dragging is not supported. Audio transcription is monophonic; Live warp/trim reconstruction is unverified and later host tempo edits do not retime the imported score. Native dry transfer is a file-copy drag, not automatic clip insertion.

Neural setup, six-language renders and timings were measured during development using the unchanged pinned Supertonic 3 backend; see [development measurements](1.1-preview.md) and [workflow](../Singing.md). Core ML requests CPUAndGPU ahead of CPU graph fallback; this does not prove every operation executes on the GPU. PSOLA runs on CPU. The score renderer never invokes Seed-VC. Neural speech adapted to singing still needs listening review.

For reproduction, build VoxGardenCheck as described in the README and pass the built VST3 and a screenshot output folder. Run pluginval with --strictness-level 10, and run Singing/test_runtime.py in the private singing Python environment. Logs are included under Validation in the release package.
